Your Claude Code sessions in the MacBook notch, plus a timer, Pomodoro and a shelf for carrying files and text between apps and Spaces.

### Install
1. Download **ClaudeNotch-0.2.1.dmg** below. It runs natively on Apple-silicon and Intel Macs, macOS 14 or later.
2. Open it and drag **ClaudeNotch** onto **Applications**. If you have an older version, replace it.
3. Open ClaudeNotch. This build isn't notarized by Apple yet, so the first time macOS says it can't verify it. Go to **System Settings → Privacy & Security**, click **Open Anyway** next to ClaudeNotch, and confirm. You only do this once.

### New in 0.2.1
- **Smooth tab switching.** The tab bar stays still while a highlight slides to the tab you pick, and its name opens as the old one folds away. Pages hand off cleanly, with a small slide in the direction you're going, and the notch resizes without bouncing.
- **Shelf names read properly.** File names get two lines instead of being cut short ("Brand guidelines.pdf", not "Brand…nes.pdf"), and links show without "www.".

Everything from 0.2.0 is still there: colour-coded Claude Code sessions with Allow / Deny, answers and replies from the notch; the timer and Pomodoro; the shelf with optional clipboard history.

Needs Claude Code (desktop app or CLI). Everything stays on your Mac.
